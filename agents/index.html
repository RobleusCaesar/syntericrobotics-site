Investor brief or field pilot.

Third-party agents can pull public facts and submit a contact over MCP. People can keep using the site or email rob@syntericrobotics.com / call 303-358-6128.

MCP ENDPOINT

HTTPS: https://api.syntericrobotics.com/mcp

Streamable HTTP. POST JSON-RPC (initialize, then tools/call). Health: GET https://api.syntericrobotics.com/health.

Discovery: /llms.txt, /.well-known/mcp.json.

TOOLS

ToolNotes
list_investor_briefPre-seed stage, focus, one-pager. No cap table. No unpublished numbers.
list_pilot_offerWhat a test looks like. Not a purchase.
create_investor_inquiryQuarantine ticket SYN-INV-…. Required: name, firm, email. Optional: check_size_range, notes. Honeypot company_website empty. Human reviews before any reply. No auto-DM.
create_pilot_inquiryQuarantine ticket SYN-PIL-…. Required: name, org, use_case, site_type, email, phone. Optional: notes. Human reviews before any site contact. No booking. No payment.

QUARANTINE

No token. Create tools open a quarantined ticket only. Nothing emails LPs, operators, or job sites automatically. Idempotent ticket ids. Confirm-by-email is optional later.

EXAMPLE

curl -sS -X POST 'https://api.syntericrobotics.com/mcp' \
  -H 'Content-Type: application/json' \
  -H 'Accept: application/json, text/event-stream' \
  -d '{"jsonrpc":"2.0","id":1,"method":"initialize","params":{"protocolVersion":"2025-03-26","capabilities":{},"clientInfo":{"name":"example-agent","version":"0.1.0"}}}'

  -H 'Content-Type: application/json' \
  -H 'Accept: application/json, text/event-stream' \
